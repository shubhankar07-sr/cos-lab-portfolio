# Lab 2.3 – TOTP MFA Findings

## Objective
Generate and verify Time-Based One-Time Passwords (TOTP) using Python and Google Authenticator.

## TOTP Generation
A TOTP secret and QR code were generated using Python.

The generated QR code was scanned using Google Authenticator for the InstaSafe Lab test user.

## TOTP Verification
The OTP generated by Python was compared with the OTP displayed in Google Authenticator.

Both OTP values matched, confirming that the TOTP secret and time synchronization were working correctly.

## TOTP Rotation
The current OTP was generated and then checked again after waiting approximately 31 seconds.

The OTP changed after the waiting period, confirming that the TOTP is time-based and rotates periodically.

## TOTP Failure Root Causes

Possible causes of TOTP authentication failure include:

1. Server and authenticator device clocks are not synchronized.
2. Incorrect TOTP secret is configured.
3. The authenticator device has incorrect date or time settings.
4. The TOTP code has expired before it is submitted.
5. Time synchronization problems between the client and server.

## Conclusion
The TOTP setup was successfully verified using Python and Google Authenticator. The matching OTP confirmed successful synchronization, and the OTP rotation test confirmed time-based OTP generation.
